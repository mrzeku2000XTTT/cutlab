Open source · timeline · real MP4

Cutlab

A map of video editors that actually have a timeline and write a playable MP4. Plus the Chinese WebAV / 剪映-draft stack. This is the starting repo for an open AI NLE — not a fake export button.

Best fork: Frontstage All repos Architecture

Rule

Preview and export must read the same timeline JSON. Export is FFmpeg or WebCodecs+mp4box. canvas.captureStream() is not an editor.

Export command we will always test

ffmpeg -y -framerate 30 -i frames/%06d.png -i mix.wav \
  -c:v libx264 -pix_fmt yuv420p -crf 18 \
  -c:a aac -b:a 192k -movflags +faststart out.mp4
ffprobe -hide_banner out.mp4
# then open in VLC
